# Laboratory 5: Cloud Data Engineer

## Mission Overview
Deployed an S3-compatible object storage server using MinIO and Docker.

## Objectives
- Differentiate between Block, File, and Object Storage
- Deploy MinIO using Docker
- Create storage buckets and upload files
- Document cloud operations

## Tools Used
- KillerCoda (Ubuntu environment)
- Docker
- MinIO
- Web Browser

## Skills Learned
- Docker container deployment with environment variables
- Object storage concepts
- Web console navigation
- Bucket creation and file upload
