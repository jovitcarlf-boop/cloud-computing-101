 Cloud Infrastructure Components

 1. **Compute Resources**
- Processing power for running applications
- CPU cores, processing capacity
- Example: EC2 instances, VMs, servers

 2. **Storage Resources**
- Persistent data storage systems
- File systems, databases, object storage
- Example: S3, Azure Blob Storage, Google Cloud Storage

 3. **Networking Resources**
- Connectivity and data transfer between components
- IP addresses, network interfaces, VPCs
- Example: Virtual Private Cloud, subnets, firewalls

 4. **Identity and Access Management (IAM)**
- Authentication and authorization services
- User and permission management
- Example: AWS IAM, Azure AD, Google Cloud IAM

 Linux Commands Executed
- `uname -a` - Display system information and kernel details
- `uname -r` - Show kernel version
- `lscpu` - List CPU architecture and information
- `nproc` - Display number of processor cores
- `free -h` - Show RAM and memory usage
- `df -h` - Display disk space usage in human-readable format
- `mount` - List all mounted file systems
- `hostname` - Display system hostname
- `ip addr show` - Show IP address and network configuration
- `lsb_release -a` - Display OS and distribution information
